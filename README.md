# Лабораторная работа № 1. Библиотека

Предметная область: библиотека (книги, авторы, читатели, выдачи).

## Файлы
- `diagram.puml` — UML-диаграмма классов (PlantUML)
- `models.py` — классы предметной области
- `exceptions.py` — собственное исключение `LibraryDataError`
- `xml_loader.py` — загрузка данных из XML в объекты
- `main.py` — запуск программы
- `data/library.xml` — исходные данные

## Запуск
```
python main.py
```
Нужен Python 3.8 или новее, сторонние библиотеки не требуются.
